regex: creating and matching patterns found in text

	a range matches a single character from the enclosed brackets []
	ex: [abc] would match on a, b, or c
	[^abc] matches any character that is not a, b, or c
	[a-z] matches any lowercase character
	[A-Z] matches any uppercase character
	[A-Za-z] matches on any uppercase or lowercase letter 
	[0-9] matches on any digit 0-9, can also be represented as \d

	A group matches every character from the enclosed characters. A group uses parentheses ()
	(abc) would match on abc
	(abc|cba) would match on abc or cba 

	A quantifier determines how many times the preceding character, group, or range occurs, using braces {}
	(a){4} would match 'aaaa'
	(abc){1,2} would match abc or abcabc
	[A-Z]{1,} would match any uppercase letter at least one time 
	[A-Z]{0, 5} would match any upercase letter at most five time
	* stands for 0 or more times
	+ stands for 1 or more times {1.}
	? stands for 0 or 1 times {0,1}

	. is a wildcard that can stand for any other character 

	anchors specify where a string must start and end 
	^ = start of a string
	$ = end of a string 
	^[ab]$ will match on ab but not on abdominal
	spaces do not seperate strings, newlines do, so a b would not match the above pattern 

	escape character: \
	using this will treat the symbol direcrtly after it as a literal character within the pattern 
	\? translates to a literal ?, not a special qunaitifer 
	\. translates to a literal period 

	phone number:
	- = a literal hyphen (no special meaning)
	for phone numbers stored in format: (###) ###-####
		\([0-9]{3}\) [0-9]{3}-[0-9]{4}
		\(\d{3}\) \d{3}-\d{4}

	to test regex in powershell:
	"a" -cmatch "[ab]"
	"(706)" -cmatch "\(\d\d\d\)"
